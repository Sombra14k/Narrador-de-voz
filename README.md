# Narrador Automático de Slides 🎙️🎬

Este projeto é um script em Python que automatiza a criação de vídeos a partir de apresentações do PowerPoint (`.pptx`). Ele extrai o texto dos slides, gera uma narração profissional usando IA e sincroniza cada áudio com a imagem do slide correspondente.

## 🚀 Funcionalidades
- Extração automática de texto de slides (incluindo grupos e tabelas).
- Narração de alta qualidade com vozes neurais (Microsoft Edge TTS).
- Geração de vídeo final em formato `.mp4`.
- Limpeza automática de textos para uma fala mais fluida.

Para rodar este projeto, você precisará instalar as seguintes bibliotecas via terminal:
